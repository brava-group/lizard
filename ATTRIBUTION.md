Every asset bundled in this repository (images, icons, fonts, data files) is listed here with its
author, source and licence. `cargo xtask assets` fails if a file under `assets/`, `docs/brand/` or
`docs/images/` is missing from this list.

FigCraft's user-interface icons use the UI3 set listed below. The FigCraft brand mark and
the fallback drawings in `crates/ui-egui/src/icons.rs` are original work,
MIT OR Apache-2.0.

## Optional background removal model (downloaded at run time)

The desktop image toolbar can install the [withoutBG Python SDK](https://github.com/withoutbg/withoutbg-python) 1.3.0 (Apache-2.0) in a user cache and download the [withoutBG Open Model](https://withoutbg.com/open-model/license) on first use. No SDK or model weights are checked into this repository or bundled with Lizard. The model contains withoutBG weights under Apache-2.0, DINOv3 material under the [Meta DINOv3 License](https://ai.meta.com/resources/models-and-libraries/dinov3-license/), and a BiRefNet branch under MIT. Built with DINOv3. Distributions that bundle model files must include the model's licenses and notices.

The desktop image vectorization action uses the [VTracer Rust crate](https://github.com/visioncortex/vtracer) 0.6.5 by Tsang Hao Fung and contributors, licensed MIT OR Apache-2.0. It is linked as a dependency; no VTracer artwork or model assets are bundled.
